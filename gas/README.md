# Заявки з сайту → Telegram

Все кроки — під вашим власним Google/Telegram акаунтом. Клієнту нічого
налаштовувати не треба: після підключення бот просто сам пише в чат.

## 1. Створити бота (2 хв)

1. У Telegram відкрийте **@BotFather** → `/newbot`.
2. Дайте назву й username (наприклад `facebody_leads_bot`).
3. BotFather видасть **токен** виду `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxx` — скопіюйте, він знадобиться нижче.

## 2. Отримати CHAT_ID

Куди слати заявки — вирішуйте самі:

- **Особисто собі**: напишіть боту `/start` (просто знайдіть його за username і натисніть Start), потім відкрийте у браузері
  `https://api.telegram.org/bot<ТОКЕН>/getUpdates` — у відповіді буде `"chat":{"id": ...}` — це і є ваш CHAT_ID (число, може бути з мінусом).
- **У групу** (зручно, якщо заявки має бачити й клієнт): створіть Telegram-групу, додайте туди бота, напишіть у групі будь-що, потім так само відкрийте `getUpdates` — `chat.id` групи зазвичай починається з `-`.

## 3. Створити Apps Script проєкт (5 хв)

1. Зайдіть на [script.google.com](https://script.google.com) під своїм Google-акаунтом → **New project**.
2. Видаліть увесь дефолтний код у `Code.gs`, вставте вміст файлу [`Code.gs`](./Code.gs) з цієї папки.
3. Зліва **Project Settings** (⚙️) → **Script Properties** → **Add script property**:
   - `BOT_TOKEN` = токен з кроку 1
   - `CHAT_ID` = id з кроку 2
4. Поверніться в редактор коду, у випадаючому списку функцій вгорі оберіть `testTelegram` → **Run**. Перший раз попросить дозволи — підтвердіть. Якщо в чат/групу прилетіло тестове повідомлення — все підключено вірно.

## 4. Задеплоїти як Web App

1. **Deploy** → **New deployment**.
2. Тип — **Web app** (шестерня зліва від "Select type").
3. Execute as: **Me**. Who has access: **Anyone**.
4. **Deploy** → скопіюйте виданий URL (`https://script.google.com/macros/s/XXXXXXXX/exec`).

## 5. Підключити до сайту

Відкрийте `js/main.js`, знайдіть на самому початку файла:

```js
const LEADS_ENDPOINT = 'YOUR_APPS_SCRIPT_WEB_APP_URL_HERE';
```

Замініть на URL з кроку 4, закомітьте й запуште. Форми на сайті одразу почнуть слати заявки боту — перевірте, надіславши тестову заявку через сайт.

## Де подивитись всі заявки одним списком

У тій же Google-таблиці, куди прив'язаний Apps Script, автоматично
з'явиться аркуш **«Ліди»** — там усе, навіть якщо Telegram колись
тимчасово не спрацює (мережева помилка тощо), заявка все одно
збережеться в таблиці.

## Якщо потрібно змінити CHAT_ID пізніше

Просто зайдіть у Project Settings → Script Properties скрипта й
відредагуйте `CHAT_ID` — сайт міняти не треба, деплой перероблювати
не треба.
